# thecrescentcove.com

Crescent Cove studio site — games, add-ons, and tools forged under a
crescent moon. Design: **Moonlit Forge** (deep night blues, crescent-moon
motif, forge-gold accents).

## Structure

- `index.html` — studio home (nav, hero, products, crew, devlog teaser, footer)
- `forge-ledger.html` — Forge's Ledger product page (features, satellite
  roadmap, download status, GitHub + Patreon links)

Both pages are fully self-contained (styles + scripts inlined) — no build
step, no external assets. Push to `main` and GitHub Pages serves it.
